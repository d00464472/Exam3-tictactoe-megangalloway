# Tic-Tac-Toe

## Description
A simple two player Tic-Tac-Toe game. Players take turns choosing positions on a 3x3 board. The game checks for wins, ties, and invalid moves.

## How to Build
Compile the program using:

```bash
make
```

## How to Run
Start the game with:

```bash
./tic-tac-toe
```

## Clean
Remove compiled files using:

```bash
make clean
```

## C++ Feature Used
`std::vector` to store the board positions.
